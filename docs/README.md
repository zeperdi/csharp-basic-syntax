## API Documentation

For detailed API documentation, see the main README.md in the project root or visit the Swagger UI when running the application locally at `https://localhost:5001`.

## Architecture

The TaskApiService follows a clean architecture approach with the following layers:

- **Controllers**: Handle HTTP requests and responses
- **Models**: Define data structures and DTOs
- **Data**: Entity Framework context and database operations
- **Tests**: Comprehensive unit and integration tests

## Deployment

The application can be deployed using Docker, Azure App Service, or any .NET 8 compatible hosting environment.
